# Community Ledger User Guide

## Introduction
Community Ledger is a multi-currency financial management system that helps groups track and manage their finances. It supports multiple currencies, shared ledgers, and collaborative financial tracking.

## Getting Started

### Authentication
1. **Login**
   - Visit the login page
   - Enter your email address
   - You'll receive a login link via email
   - Click the link to access your account

### Groups

#### Creating a Group
1. Click "New Group" on the groups page
2. Enter:
   - Group name (required)
   - Description (optional)
3. Click "Save Group"

#### Managing Group Members
1. Navigate to your group
2. Click "Add Member"
3. Enter the member's email address
4. Members can be removed using the "Remove" button next to their name

### Projects

#### Creating a Project
1. Navigate to a group
2. Click "New Project"
3. Enter the project name
4. Click "Save Project"

#### Managing Project Members
1. Navigate to the project
2. Click "Add Member"
3. Enter the member's email address
4. Members can be removed using the "Remove" button

### Accounts

#### Creating an Account
1. Navigate to a project
2. Click "Add Account"
3. Enter:
   - Account name
   - Select currency type (USD, EUR, GBP, JPY, CNY)
4. Click "Save Account"

#### Managing Accounts
- View account balance and transactions from the project page
- Edit account details by clicking "Edit"
- Delete accounts using the "Delete" button
- View account summaries by currency in the edit page

### Ledgers

#### Creating a Ledger
1. Navigate to a project
2. Click "Add Ledger"
3. Enter:
   - Ledger name
   - Description (optional)
   - Select currency type
4. Click "Save Ledger"

#### Managing Ledgers
- View ledger details by clicking on the ledger name
- Edit ledger details by clicking "Edit"
- Delete ledgers using the "Delete" button

### Entries

#### Adding an Entry
1. Navigate to a ledger
2. Click "Add Entry"
3. Enter:
   - Amount (can be positive or negative)
   - Description
   - Memo (optional)
   - Category (optional)
   - Select currency
   - Select account
4. Click "Save Entry"

#### Managing Entries
- View all entries in the ledger page
- Edit entries by clicking "Edit"
- Delete entries using the "Delete" button

## Features

### Multi-Currency Support
- Support for USD, EUR, GBP, JPY, and CNY
- Each account and ledger can have its own currency
- Entries can be made in any supported currency
- Account summaries show totals by currency

### Organizational Structure
1. **Groups**
   - Top-level organization unit
   - Contains projects and members
   - Members can access all projects in the group

2. **Projects**
   - Contains accounts and ledgers
   - Has its own member list
   - Members can access all accounts and ledgers

3. **Accounts**
   - Track balances in specific currencies
   - Connected to entries for transaction tracking
   - Show currency-specific summaries

4. **Ledgers**
   - Group related financial entries
   - Support multiple currencies
   - Link entries to accounts

### Entry Details
- Amount (positive or negative)
- Description
- Optional memo for additional notes
- Optional category for classification
- Currency selection
- Account association

## Best Practices

1. **Organization**
   - Create groups for distinct organizations or purposes
   - Use projects to separate different financial activities
   - Create accounts for different types of funds
   - Use ledgers to group related transactions

2. **Currency Management**
   - Choose appropriate currencies for accounts based on primary usage
   - Use the memo field to note exchange rates if relevant
   - Monitor account summaries for currency exposure

3. **Record Keeping**
   - Add detailed descriptions to entries
   - Use categories consistently for better organization
   - Add memos for important context or references
   - Regularly review account summaries

4. **Collaboration**
   - Add all relevant members to groups and projects
   - Use descriptive names for accounts and ledgers
   - Document important decisions in entry memos
